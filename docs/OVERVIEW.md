# Project Overview: Spillburg Logistics 1 (Private) Limited

Spillburg Logistics 1 (Private) Limited is the dedicated multimodal freight forwarding, licensed customs brokerage, bonded warehousing, and logistics engineering operating company of the **Spillburg Group** in Colombo, Sri Lanka.

## Repository Profile & Metadata Checklist

- **Repository**: `https://github.com/muhzahjr07/sp_logistics1`
- **Short Description**: 
  > Enterprise multimodal freight forwarding platform, RFQ quotation engine, and administrative operations console for Spillburg Logistics 1 (Colombo, Sri Lanka). Built with PHP 8.2+, SQLite/MySQL PDO, and Google Stitch design system.
- **Website URL**: `https://spillburglogistics1.com` (or deployment preview URL)
- **Topics / Tags**:
  `freight-forwarding`, `logistics`, `maritime`, `shipping`, `supply-chain`, `php`, `colombo-port`, `quote-system`, `rfq-dockets`, `customs-clearance`, `cargo-tracking`, `admin-dashboard`

---

## Architecture & Technology Stack

| Layer | Implementation | Details |
|---|---|---|
| **Core Runtime** | PHP 8.2+ / 8.3+ | Strict types, modular template components, zero-dependency native stack |
| **Database** | Universal PDO | Dual-driver support: zero-config SQLite 3 (WAL mode) & enterprise MySQL 8.0+ / MariaDB |
| **Frontend** | HTML5 / Vanilla CSS3 / Modern JS | Google Stitch "Maritime Logistics Precision" design system tokens, responsive mobile drawer |
| **Security** | OWASP Top 10 Hardened | CSRF token defense, anti-spam honeypot, XSS context filtering, prepared statements, bcrypt hashing |
| **Admin Console** | `/admin` | Real-time cargo statistics, RFQ status workflow, CSV exports, port bulletins CRUD, settings |
